# Help Commands

## [Prisma](https://www.prisma.io)

## Reset your database

```bash
npx prisma migrate reset
```

## Migrate your database

```bash
npx prisma migrate dev
```

## Generate your Prisma Client

```bash
npx prisma generate
```

## [Coderabbit](https://www.coderabbit.ai)

## Run your first review

```bash
coderabbit
```

## Use plain mode or prompt-only mode when using it with Claude Code, Codex CLI, Gemini CLI, etc

```bash
coderabbit review --plain
```

## Show minimal output optimized for AI agents

```bash
coderabbit --prompt-only
```

## Run your app

```bash
npm run dev
```

## [Inngest](https://www.inngest.com)

## Run your Inngest agent

```bash
npx inngest-cli@1.12.1 dev
```

## Deploy your Inngest agent

```bash
npx inngest-cli@1.12.1 deploy
```

## Deploy your app

```bash
npm run deploy
```
