# QuickAI

## QuickAI is a full-stack web application that allows users to generate AI-powered content, such as articles, blog titles, and images, using OpenAI's API.

## Technologies

- React
- Node.js
- Express
- OpenAI
- Tailwind CSS
- Clerk
- Vercel

## Live example
- Server: https://quick-ai-server-ten-rosy.vercel.app/
- Client: https://quick-ai-five-swart.vercel.app/

## How to run the project

- Clone the repository
- Install dependencies
- Set up environment variables
- Run the server
- Run the client
