# QuickGPT - AI-Powered Chat Application

QuickGPT is a modern, AI-powered chat application built with React that provides both text generation and image generation capabilities. The application features a sleek, responsive interface with dark mode support and a comprehensive chat management system.

## 🚀 Features

### Core Functionality

- **AI Text Generation**: Engage in intelligent conversations with AI-powered responses
- **AI Image Generation**: Create stunning images from text prompts
- **Multi-Chat Management**: Create, manage, and switch between multiple chat sessions
- **Search Functionality**: Quickly find specific conversations with the built-in search feature
- **Dark/Light Theme**: Toggle between dark and light modes for comfortable viewing
- **Responsive Design**: Fully responsive interface that works seamlessly on desktop and mobile devices

### User Features

- **Credits System**: Track and manage AI generation credits
- **Subscription Plans**: Multiple tier options (Basic, Pro, Premium) with varying features
- **Community Gallery**: Browse and share AI-generated images with the community
- **User Authentication**: Secure login and user management
- **Chat History**: Persistent chat history with timestamps
- **Message Publishing**: Share generated images with the community

## 🛠️ Technologies Used

- **Clerk**: A user authentication platform that provides tools for building secure and scalable authentication systems
